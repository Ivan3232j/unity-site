# unity-site

Unity Station — учебный сайт курса Unity.

Сайт: https://ivan3232j.github.io/unity-site/

## Содержимое

- Модуль 2: кликер, уроки 7–12.
- Модуль 3: раннер, уроки 13–18 (текущая версия материалов).

Статический сайт без сборки. Для локального просмотра откройте `index.html`.

GitHub Pages: публикация из ветки `main`, папка `/`.

Исходные документы преподавателя и рабочие материалы уроков остаются в локальной папке и не входят в публикацию.
